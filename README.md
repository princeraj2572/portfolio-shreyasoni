# Shreya Soni — Portfolio

Personal portfolio site, built with [Next.js](https://nextjs.org) (App Router, TypeScript, Tailwind CSS v4).

## Pages

- `/` — Home / Hero
- `/about` — About Me
- `/education` — Education timeline
- `/experience` — Work experience
- `/projects` — Featured project
- `/skills` — Skills & interests
- `/certifications` — Certifications
- `/contact` — Contact & languages

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
